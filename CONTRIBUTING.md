# Contributing

mise is not accepting pull requests from external contributors, and GitHub does
not let them be created. Report bugs in
[Issues](https://github.com/jdx/mise/issues), and bring questions, ideas and
feature requests to [Discussions](https://github.com/jdx/mise/discussions).
Report only problems you ran into while using mise.

The [contributing guide](https://mise.jdx.dev/contributing.html) covers what a
report needs and how to build and test mise from source, including the
[mbx build cache](https://mise.jdx.dev/contributing.html#cargo-build-cache)
that wraps `cargo`. For documentation work, also read
[Working on the mise docs](docs/README.md).
