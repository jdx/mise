# loongarch64 and riscv64 support

A small release that recognizes `loongarch64` and `riscv64` as valid platform arches and refreshes the conda (rattler) backend.

## Fixed

- Add `loongarch64` and `riscv64` to the set of arches accepted by `Platform::validate()`. Previously, lockfiles targeting `linux-riscv64` or `linux-loongarch64` would fall back to the common platform set instead of resolving to the requested single platform, so installs on those machines couldn't use lockfile-authoritative platform selection ([#10038](https://github.com/jdx/mise/pull/10038) by @k0tran).

## Changed

- Bump `rattler` (used by the conda backend) from 0.42 to 0.43, picking up upstream fixes for missing symlinks during Windows installs, deterministic path ordering from `link_package_sync`, and accepting full URLs as the OAuth issuer host ([#10030](https://github.com/jdx/mise/pull/10030)).
