mise v2026.1.2 includes several important bug fixes and security improvements, particularly addressing version management edge cases and enhancing the tool's reliability across different scenarios.

This release also strengthens our GitHub workflow security to prevent potential code execution from untrusted sources, ensuring the safety of our development process and community contributions.

### Bug Fixes

**Version Management Improvements**
- Fixed an issue where pre-release versions were incorrectly included when using `latest` with `install_before` ([#7631](https://github.com/jdx/mise/pull/7631)) - thanks to @koh-sh
- Enhanced version filtering to properly exclude test versions (e.g., `1.0.0-test`) from stable version lists ([#7647](https://github.com/jdx/mise/pull/7647)) - thanks to @belgio99
- Resolved a year-boundary bug that caused `mise self-update` to fail when crossing into a new year ([#7611](https://github.com/jdx/mise/pull/7611))

**Backend and Asset Detection**
- Added support for `.artifactbundle.zip` files in asset selection, improving compatibility with certain tool distributions ([#7657](https://github.com/jdx/mise/pull/7657)) - thanks to @swizzlr
- Fixed HTTP backend to properly fallback to configuration when fetching tool options ([#7655](https://github.com/jdx/mise/pull/7655)) - thanks to @roele

**Task System**
- Corrected tool inheritance behavior in [tasks](https://mise.jdx.dev/tasks/) when using intermediate parent configurations ([#7637](https://github.com/jdx/mise/pull/7637)) - thanks to @chadxz

### Security

- Implemented safeguards in our GitHub workflows to prevent potential code execution from untrusted forks, enhancing the security of our development process

### New Tools

- Added support for [oha](https://github.com/hatoo/oha), a modern HTTP load testing tool ([#7633](https://github.com/jdx/mise/pull/7633)) - thanks to @jylenhof
