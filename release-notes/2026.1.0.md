mise v2026.1.0 brings several exciting improvements to enhance your development workflow. This release introduces the Forgejo backend for managing tools from self-hosted Forgejo instances, adds powerful new task runner capabilities, and improves npm/node integration. We've also squashed numerous bugs related to archive extraction and platform-specific behaviors.

A special welcome to our new contributors: @ll-nick, @sushichan044, @phm07, @granstrand, @h3y6e, and @matixlol\! Your contributions help make mise better for everyone.

### Highlights

**New Forgejo Backend** ([#7469](https://github.com/jdx/mise/pull/7469))
mise now supports installing tools from Forgejo instances, expanding beyond GitHub to support self-hosted git forges. This allows teams using Forgejo to manage their internal tools seamlessly. Learn more in the [Forgejo backend documentation](https://mise.jdx.dev/backends/forgejo.html).

**Enhanced npm Management** ([#7559](https://github.com/jdx/mise/pull/7559), [#7557](https://github.com/jdx/mise/pull/7557))
You can now override Node.js's bundled npm with a specific version, giving you precise control over your npm toolchain. Additionally, npm itself is now available as a standalone tool in the registry (`mise use npm@latest`).

**Task Runner Improvements**
- **Naked task completions** ([#7524](https://github.com/jdx/mise/pull/7524)): Shell completions now work for tasks without the `mise run` prefix, and the `:::` separator is supported for better organization
- **New settings** for task behavior: control whether scripts are parsed for dependencies ([#7471](https://github.com/jdx/mise/pull/7471)) and display full command output ([#7344](https://github.com/jdx/mise/pull/7344))
- **Monorepo support** ([#7478](https://github.com/jdx/mise/pull/7478)): Task directories in monorepos now load correctly even without a config file

Learn more about these features in the [tasks documentation](https://mise.jdx.dev/tasks/).

### Tool & Environment Management

- **Post-install hooks** now receive tool context environment variables ([#7521](https://github.com/jdx/mise/pull/7521)), making it easier to configure tools after installation. See the [hooks documentation](https://mise.jdx.dev/hooks.html) for details.
- **SOPS integration** now respects standard SOPS environment variables ([#7461](https://github.com/jdx/mise/pull/7461)), improving compatibility with existing SOPS workflows
- **Bun installations** via npm are now always hoisted for better consistency ([#7542](https://github.com/jdx/mise/pull/7542))

### Bug Fixes

- **Archive extraction**: Fixed issues with `.tar` files not extracting properly ([#7567](https://github.com/jdx/mise/pull/7567)) and improved asset matching for mixed archive/binary releases ([#7566](https://github.com/jdx/mise/pull/7566))
- **Platform-specific fixes**: 
  - Windows now correctly prioritizes `.zip` files ([#7568](https://github.com/jdx/mise/pull/7568))
  - Linux also prefers `.zip` over non-archive extensions ([#7587](https://github.com/jdx/mise/pull/7587))
  - Windows hardlink shims now properly trigger reshimming ([#7537](https://github.com/jdx/mise/pull/7537))
- **Tool-specific fixes**:
  - Aqua backend correctly handles tree-sitter binary paths ([#7535](https://github.com/jdx/mise/pull/7535))
  - npm update notifications are now suppressed ([#7556](https://github.com/jdx/mise/pull/7556))
  - kerl update output is quieted for cleaner logs ([#7467](https://github.com/jdx/mise/pull/7467))
