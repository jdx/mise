# Reject wrong-arch release assets

A small fix release that hardens GitHub release asset auto-selection against picking binaries for the wrong CPU architecture.

## Fixed

- **(github)** Asset auto-selection now hard-rejects any candidate whose filename explicitly declares a non-matching architecture, even when other scoring bonuses (preferred name, archive type, libc match) would otherwise rank it first. This fixes cases like `cargo-msrv` on aarch64 Linux, where `cargo-msrv-x86_64-unknown-linux-gnu-*.tgz` was being chosen over no-match-better-than-wrong-match. Explicit `asset_pattern` configuration is unchanged ([#10018](https://github.com/jdx/mise/pull/10018) by @jdx).
