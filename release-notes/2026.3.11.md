> **Note:** This release has no binary assets due to a CI failure caused by a breaking change in [usage v3.1.0](https://github.com/jdx/usage/releases/tag/v3.1.0). The fix is in [#8715](https://github.com/jdx/mise/pull/8715). All changes below are included in the next release.

This release adds `--skip-tools` for faster task execution, GitHub token auto-detection from `gh` CLI, optional `args`/`env` fields in task `run` entries, and fixes across lockfiles, shims, tasks, and environment handling.

## Highlights

- **`mise run --skip-tools`** -- Skip tool installation when running tasks, useful when you know tools are already installed and want faster execution. [#8699](https://github.com/jdx/mise/pull/8699) by @jdx
- **GitHub token auto-detection from `gh` CLI** -- mise now reads GitHub tokens from `gh`'s `hosts.yml` config, so authenticated GitHub API requests work automatically if you're logged in with `gh auth login`. [#8692](https://github.com/jdx/mise/pull/8692) by @jdx
- **Optional `args` and `env` in task `run` entries** -- Task run entries now support optional `args` and `env` fields for more flexible task configuration. [#8687](https://github.com/jdx/mise/pull/8687) by @jdx

## Added

- **`mise run --skip-tools`** -- Skip tool installation when running tasks. [#8699](https://github.com/jdx/mise/pull/8699) by @jdx
- **GitHub token from `gh` CLI** -- Automatically read tokens from `gh` CLI's `hosts.yml` config. [#8692](https://github.com/jdx/mise/pull/8692) by @jdx
- **Task `run` entries support `args` and `env`** -- Optional fields for more flexible task definitions. [#8687](https://github.com/jdx/mise/pull/8687) by @jdx
- **vfox: `try_get`, `try_head`, `try_download_file`** -- Non-failing HTTP methods for Lua plugins. [#8697](https://github.com/jdx/mise/pull/8697) by @jdx
- **New registry tools:**
  - [rtk](https://github.com/rtk-ai/rtk) -- [#8683](https://github.com/jdx/mise/pull/8683) by @bricelalu

## Fixed

- **Node: expand tilde in `default_packages_file` path** -- `~/.default-node-packages` now resolves correctly. [#8709](https://github.com/jdx/mise/pull/8709) by @jdx
- **Lockfile: skip global config lockfile by default** -- Global config no longer generates a lockfile unless explicitly configured. [#8707](https://github.com/jdx/mise/pull/8707) by @jdx
- **Lockfile: respect existing platforms when running `mise lock`** -- Existing platform entries in lockfiles are preserved instead of being overwritten. [#8708](https://github.com/jdx/mise/pull/8708) by @jdx
- **GitHub: rename correct binary when archive contains multiple executables** -- Archives with multiple binaries no longer rename the wrong one. [#8700](https://github.com/jdx/mise/pull/8700) by @jdx
- **Task: include idiomatic version files in monorepo task toolset** -- `.node-version`, `.python-version`, etc. are now picked up in monorepo task directories. [#8702](https://github.com/jdx/mise/pull/8702) by @jdx
- **Task: strip inline args when validating `run.tasks` references** -- Task references with inline args (e.g. `"build --release"`) no longer fail validation. [#8701](https://github.com/jdx/mise/pull/8701) by @jdx
- **Task: inherit `task_config.dir` for included TOML and file tasks** -- Included tasks now correctly inherit the configured working directory. [#8689](https://github.com/jdx/mise/pull/8689) by @jdx
- **Task: improve error message when task files are not executable** -- Clearer error when a file task lacks execute permission. [#8705](https://github.com/jdx/mise/pull/8705) by @jdx
- **Task: improve usage spec element support** -- Better handling of usage spec elements in task definitions. [#8623](https://github.com/jdx/mise/pull/8623) by @nkakouros
- **Install: skip redundant provenance verification when lockfile has integrity data** -- Avoids duplicate verification work. [#8688](https://github.com/jdx/mise/pull/8688) by @jdx
- **Install: skip GitHub API calls for aqua tools in `--locked` mode** -- Locked installs no longer make unnecessary API calls. [#8679](https://github.com/jdx/mise/pull/8679) by @jdx
- **Shim: detect shims by checking shims directory instead of binary name** -- Fixes edge cases where shim detection failed. [#8694](https://github.com/jdx/mise/pull/8694) by @jdx
- **Shell: error when no version specified instead of silent no-op** -- `mise shell node` now shows an error instead of doing nothing. [#8693](https://github.com/jdx/mise/pull/8693) by @jdx
- **Env: support multiple `--env`/`-E` flags** -- Multiple environment overrides can now be specified. [#8686](https://github.com/jdx/mise/pull/8686) by @jdx
- **Env: make module vars available in Tera template context** -- Environment variables from env plugins are now accessible in Tera templates. [#8682](https://github.com/jdx/mise/pull/8682) by @victor-founder
- **Config: recognize SSH and other non-HTTPS URLs in `get_repo_url`** -- SSH-style git URLs are now handled correctly. [#8666](https://github.com/jdx/mise/pull/8666) by @modestman
- **Implode: include system data dir in cleanup** -- `mise implode` now removes system-level data directories. [#8696](https://github.com/jdx/mise/pull/8696) by @jdx
- **Respect `MISE_COLOR=0` for error output** -- `color_eyre` error formatting now honors the color setting. [#8690](https://github.com/jdx/mise/pull/8690) by @jdx
- **Windows: add usage tool registry support** -- [#8713](https://github.com/jdx/mise/pull/8713) by @jdx
