## Related tools

- [hk](https://hk.jdx.dev/): run Git hooks and project lint checks.
- [pitchfork](https://pitchfork.jdx.dev/): supervise long-running development processes.
- [usage](https://usage.jdx.dev/): define CLI arguments, help, and completions; mise uses it
  for [task arguments](/tasks/task-arguments.html).
