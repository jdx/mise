# Contact

Report bugs in [GitHub Issues](https://github.com/jdx/mise/issues) and ask
questions in [GitHub Discussions](https://github.com/jdx/mise/discussions/new/choose),
where answers stay searchable for other users.

| To                                                | Use                                                                                                                                                                                                                                                                   |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Report a bug                                      | [GitHub Issues](https://github.com/jdx/mise/issues). Include the command you ran, the relevant config, the expected and actual behavior, and your `mise doctor` output after you review it for private details. Check [Troubleshooting](/troubleshooting.html) first. |
| Ask a question                                    | [GitHub Discussions](https://github.com/jdx/mise/discussions/new/choose)                                                                                                                                                                                              |
| Get help when you are not sure it is a bug        | [Troubleshooting discussions](https://github.com/jdx/mise/discussions/categories/troubleshooting-and-bug-reports)                                                                                                                                                     |
| Suggest a feature                                 | [Ideas](https://github.com/jdx/mise/discussions/categories/ideas). Describe the workflow you want to improve and what you have tried.                                                                                                                                 |
| Follow project news                               | [Announcements](https://github.com/jdx/mise/discussions/categories/announcements)                                                                                                                                                                                     |
| Chat with other users                             | [Discord](https://discord.gg/mABnUDvP57)                                                                                                                                                                                                                              |
| Report a security vulnerability privately         | [SECURITY.md](https://github.com/jdx/mise/blob/main/SECURITY.md#reporting-a-vulnerability)                                                                                                                                                                            |
| Send a fix or a docs change                       | [Contributing](/contributing.html)                                                                                                                                                                                                                                    |
| Reach Jeff privately, including about sponsorship | [jdx.dev/contact](https://jdx.dev/contact/)                                                                                                                                                                                                                           |

Using AI to reply to an Issue or Discussion is restricted, and breaking the
rule gets you banned from all of jdx's projects; read the
[community participation policy](/contributing.html#community-participation)
before you post.
