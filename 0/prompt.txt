- Any unresolved conflict pauses shared-branch publication and incoming application for the entire setup.
- Local checkpoints, fetching, and eligible machine-recovery backups continue.

- Keep per-file resolution choices, but record those choices without partially applying the setup. Resume only after all conflicts are resolved.
- Recompute and validate the plan against current local and remote versions before resuming. A later edit invalidates any resolution based on an older version.
- Preserve explicit path selection for local rollback; it must not become a way to bypass the global sharing pause.

Preflight the complete incoming batch, including newly declared files and required template sources. Keep protective checkpoints and journaling for mid-write failures. Attempt safe recovery without overwriting concurrent user edits; persist an actionable failure if recovery cannot complete. Describe this as all-or-nothing application, not truly atomic filesystem writes.
